M33K X C5

Seeed XIAO ESP32-C5 companion

Connect the C5 by USB, then start the installer below.

Use a desktop browser with Web Serial support. The installer must be opened over HTTPS or localhost.

Install flow

  1. Flash the Watch.
  2. Flash the C5.
  3. Power both devices near each other for first-time pairing.

Use a USB data cable. Disconnect the other ESP device while flashing so the correct serial port is easy to identify.
