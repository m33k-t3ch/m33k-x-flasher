M33K X Watch

LilyGO T-Watch Ultra

Connect the Watch with a USB data cable, then start the installer.

Use a desktop browser with Web Serial support. The installer must be opened over HTTPS or localhost.
ESP32-C5

M33K X C5

Seeed XIAO ESP32-C5 companion

Connect the C5 with a USB data cable, then start the installer.

Use a desktop browser with Web Serial support. The installer must be opened over HTTPS or localhost.

Install

  1. Connect and flash the Watch.
  2. Connect and flash the C5.
  3. Power both devices near each other for first-time pairing.

Flash one device at a time so the correct serial port is easy to identify.
